HERBERT GORO — WEBSITE FILES

1. Extract the ZIP completely.
2. Open Herbert_Goro_Website/index.html to view the website.
3. To host elsewhere, upload the contents of Herbert_Goro_Website to a static website host.

Editing:
- index.html: page content, contact links and credential cards.
- styles.css and sections.css: design and responsive layout.
- script.js: navigation and animation.
- credentials.js: document viewer, zoom and download behaviour.
- assets/: logos, fonts and original certificate images.

Keep the files and folders together so images, fonts and links continue to work.
The notebook is not included in this website version.
